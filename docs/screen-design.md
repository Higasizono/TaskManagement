## 1. トップページ (`/`)

### 1-1. 概要

| 項目 | 内容 |
|------|------|
| URL | `/` |
| 役割 | ボードの一覧表示・作成・削除 |
| 初期状態 | API取得中は「読み込み中...」を表示 |

---

### 1-2. コンポーネント構成

実装対応: `frontend/src/pages/TopPage.tsx`、`frontend/src/components/`

```
<App>                                    src/App.tsx（React Routerのルート定義）
└── <TopPage>                            src/pages/TopPage.tsx
    ├── <header>                         インラインJSX（独立コンポーネントではない）
    │   └── アプリ名テキスト
    ├── <main>                           インラインJSX
    │   ├── エラーメッセージ / 「読み込み中...」
    │   ├── <BoardCard> × N              src/components/BoardCard.tsx
    │   │   ├── ボード名ボタン（クリックでボードページへ遷移）
    │   │   └── 「×」ボタン（aria-label="削除"）
    │   └── <CreateBoardForm>            src/components/CreateBoardForm.tsx
    │       ├── 「＋ 新しいボード」ボタン（未展開時）
    │       └── <form>（展開時）
    │           ├── <input>（自動フォーカス）
    │           ├── エラーメッセージ（API失敗時）
    │           └── 「作成」「キャンセル」ボタン
    └── <ConfirmDialog>                  src/components/ConfirmDialog.tsx
                                         削除対象が選択されているときのみ描画。
                                         ネイティブ<dialog>のshowModal()を使用
```

### 1-3. 状態別レイアウト

**通常状態（ボードあり）**

```
┌─────────────────────────────────────────────────┐
│  タスク管理アプリ                                  │
├─────────────────────────────────────────────────┤
│                                                  │
│  ┌────────────────┐  ┌────────────────┐          │
│  │ スクール課題  × │  │ 個人プロジェ  × │          │
│  └────────────────┘  └────────────────┘          │
│  ┌──────────────────────┐                        │
│  │  ＋ 新しいボード      │  ← 一覧の末尾に並ぶ      │
│  └──────────────────────┘                        │
│                                                  │
└─────────────────────────────────────────────────┘
```

ボードカードと作成ボタンは同じ横並びコンテナに入り、画面幅を超えると折り返す。
ボードが0件の場合は作成ボタンのみが表示される（専用の空状態メッセージは無い）。

**ボード作成フォーム表示中**

作成ボタンがその場でフォームに置き換わる（幅220pxのカード内に縦積み）。

```
┌─────────────────────────────────────────────────┐
│  タスク管理アプリ                                  │
├─────────────────────────────────────────────────┤
│                                                  │
│  ┌────────────────┐  ┌────────────────────┐      │
│  │ スクール課題  × │  │ ┌────────────────┐ │      │
│  └────────────────┘  │ │ ボード名        │ │      │
│                      │ └────────────────┘ │      │
│                      │ ボードの作成に失敗  │ ←API │
│                      │ しました            │  失敗時 │
│                      │ [作成] [キャンセル] │      │
│                      └────────────────────┘      │
└─────────────────────────────────────────────────┘
```

「作成」ボタンは入力が空の間および送信中は非活性。

**削除確認ダイアログ**

```
┌──────────────────────────────────────┐
│  ボードを削除しますか？               │
│                                      │
│  「スクール課題」を削除します。       │
│  配下のカラム・カードも               │
│  すべて削除されます。                 │
│                                      │
│  削除に失敗しました。          ← API失敗時 │
│  もう一度お試しください                │
│                                      │
│         [キャンセル]  [削除する]      │
└──────────────────────────────────────┘
```

ネイティブの `<dialog>` 要素を `showModal()` で開くため、フォーカスのダイアログ内への移動・
フォーカストラップ・Escキーでのキャンセル・背面要素の不活性化はブラウザ標準の挙動による。
初期フォーカスは「キャンセル」ボタンに当たる。

---

### 1-4. インタラクション仕様

| 操作 | 挙動 |
|------|------|
| ボードカードをクリック | `/board/:id` に遷移 |
| 「×」ボタンをクリック | 削除確認ダイアログを表示 |
| 「＋ 新しいボード」クリック | インライン入力フォームに切り替わる。フォーカスが自動的に入力フィールドへ移動 |
| Enter（フォーム内） | バリデーション → 成功時：ボード作成・一覧更新。失敗時：エラー表示 |
| 「キャンセル」クリック（フォーム内） | フォームを閉じる |
| Esc（削除確認ダイアログ表示中） | ダイアログを閉じる（削除しない） |

## 2. ボードページ (`/board/:id`)

### 2-1. 概要

| 項目 | 内容 |
|------|------|
| URL | `/board/:id` |
| 役割 | カラムとカードの表示・カードの追加・編集・削除・並び替え |
| 初期状態 | 「未着手」「進行中」「完了」の3カラムを常に表示（0件になることはない） |

---

### 2-2. コンポーネント構成

実装対応: `frontend/src/pages/BoardPage.tsx`、`frontend/src/components/`

```
<App>                                    src/App.tsx
└── <BoardPage>                          src/pages/BoardPage.tsx
    ├── <header>                         インラインJSX
    │   ├── 「← 戻る」ボタン
    │   └── ボード名テキスト
    └── <main>
        ├── エラーメッセージ / 「読み込み中...」
        └── <DndContext>                 @dnd-kit/core。センサー・衝突判定を保持
            ├── 横スクロールコンテナ（インラインJSX）
            │   └── <BoardColumn> × 3    src/components/BoardColumn.tsx
            │       │                    未着手・進行中・完了に固定。useDroppable
            │       ├── カラム名テキスト（<h2>）
            │       ├── <SortableContext> @dnd-kit/sortable
            │       │   ├── <CardItem> × N   src/components/CardItem.tsx
            │       │   │   │                useSortable
            │       │   │   ├── ドラッグハンドル（⠿）
            │       │   │   ├── カード名ボタン（クリック / Enterで編集モード）
            │       │   │   ├── <form>（編集モード時に置き換わる）
            │       │   │   │   ├── <input>（自動フォーカス・全選択）
            │       │   │   │   └── バリデーションエラーメッセージ
            │       │   │   ├── 保存失敗時のエラーメッセージ
            │       │   │   └── 「×」ボタン（aria-label="削除"）
            │       │   └── 「カードはまだありません」（カード0件のとき）
            │       └── <CreateCardForm>  src/components/CreateCardForm.tsx
            │           ├── 「＋ カードを追加」ボタン（未展開時）
            │           └── <form>（展開時）
            │               ├── <input>（自動フォーカス）
            │               ├── エラーメッセージ（API失敗時）
            │               └── 「追加」「キャンセル」ボタン
            └── <DragOverlay>            ドラッグ中のカードのゴースト表示
```

カード編集フォームは `CardItem` に内包されており、独立したコンポーネントにはなっていない。

### 2-3. 状態別レイアウト

**通常状態（カラム・カードあり）**

```
┌──────────────────────────────────────────────────────────────────────┐
│  ← 戻る   スクール課題                                                │
├────────────────┬────────────────┬────────────────────────────────────┤
│  未着手        │  進行中        │  完了                              │
│  ────────────  │  ────────────  │  ────────────                      │
│ ⠿ デザイン   × │ ⠿ コーディン × │ ⠿ 要件定義   ×                     │
│ ⠿ テスト計画 × │                │                                    │
│                │                │                                    │
│  ＋ カードを   │  ＋ カードを   │  ＋ カードを                       │
│    追加        │    追加        │    追加                            │
└────────────────┴────────────────┴────────────────────────────────────┘
```

各カードの左端の `⠿` がドラッグハンドル。カード名はボタン要素で、クリックまたは
Enter / Space で編集モードに入る。

**カードが0件のカラム**

```
┌────────────────┐
│  完了          │
│  ────────────  │
│                │
│  カードはまだ  │
│  ありません    │
│                │
│  ＋ カードを   │
│    追加        │
└────────────────┘
```

**カード追加フォーム（インライン展開）**

```
カラム末尾の「＋ カードを追加」ボタンが、その場でフォームに置き換わる。

```
┌────────────────┐
│  未着手        │
│  ────────────  │
│ ⠿ デザイン   × │
│                │
│ ┌────────────┐ │
│ │ カード名   │ │
│ └────────────┘ │
│ カードの作成に │  ← API失敗時のみ
│ 失敗しました   │
│  [追加][ｷｬﾝｾﾙ] │
└────────────────┘
```

「追加」ボタンは入力が空の間および送信中は非活性。クライアント側の文字数チェックは行わない
（100文字超はサーバー側で400となる）。

**カード編集モード（インライン）**

```
┌────────────────┐
│ ⠿ ┌──────────┐ │
│   │デザインを考│ │  ← タイトルがinputに変わる（全選択状態）
│   └──────────┘ │ ×
│ カード名を入力 │  ← バリデーションエラー時のみ
│ してください   │
└────────────────┘
```

**ドラッグ中の表示**

```
┌────────────────┐    ╔════════════════╗
│  未着手        │    ║  進行中        ║  ← 移動先カラム全体を
│  ────────────  │    ║  ────────────  ║     枠線でハイライト
│ ⠿ デザイン   × │    ║ ⠿ コーディン × ║
│ ⠿ テスト計画 × │    ║                ║  ← 並び替え対象のカードが
│   （半透明）   │    ║                ║     ずれて挿入位置を示す
│  ＋ カードを   │    ║  ＋ カードを   ║
│    追加        │    ║    追加        ║
└────────────────┘    ╚════════════════╝

        ┌────────────┐
        │ テスト計画  │  ← DragOverlay。ポインタに追従するゴースト
        └────────────┘
```

ドロップ位置を示す専用のガイドラインは表示しない。挿入位置は SortableContext による
カードのずれで示され、移動先カラムは枠線のハイライトで示される。

### 2-4. インタラクション仕様

| 操作 | 挙動 |
|------|------|
| 「← 戻る」クリック | トップページへ遷移 |
| カードタイトルをクリック | 編集モードに切り替わる。テキスト全選択状態。タイトルはボタン要素のためTab到達・Enter / Spaceでの起動も可能 |
| カード「×」クリック | 確認なしで即時削除 |
| 「＋ カードを追加」クリック | カラム内にフォームを展開。自動フォーカス |
| カードをドラッグ | ドラッグ中のカードを半透明にし、ポインタに追従するゴースト（DragOverlay）を表示。移動先カラム全体を枠線でハイライト |
| Enter（各フォーム内） | バリデーション後に保存 |
| Esc（カード編集中） | 編集をキャンセルし、元のタイトルに戻す |
| Esc（ドラッグ中） | ドラッグをキャンセルする（dnd-kit標準の挙動） |
| 「キャンセル」クリック（カード追加フォーム内） | フォームを閉じる |
| ページをスクロール（横） | カラムが画面幅を超えた場合、横スクロールで表示 |
